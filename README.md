# PiggyCat

PiggyCat es una aplicación web de finanzas personales que permite registrar, organizar y analizar ingresos y gastos mediante una interfaz moderna e intuitiva.

## Tecnologías

- React
- Tailwind CSS
- Express.js
- PostgreSQL

## Funcionalidades

- Registro de ingresos
- Registro de gastos
- Dashboard financiero
- Categorías de movimientos
- Estadísticas y visualización de datos
